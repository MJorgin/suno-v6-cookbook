# Genre Prompt Playbooks

These playbooks describe original stylistic directions. They intentionally avoid instructions to imitate named artists.

| Playbook | Default route | Best for |
|---|---|---|
| [Mandopop Ballad](../library/genres/mandopop-ballad.md) | `v6` | Chinese emotional melody and polished ballad production |
| [Cantopop Electropop](../library/genres/cantopop-electropop.md) | `v6` | Sleek Cantonese city pop and electronic grooves |
| [English Indie Pop](../library/genres/english-indie-pop.md) | `v6` | Personal guitar/synth hooks |
| [Hip-Hop and Trap](../library/genres/hip-hop-trap.md) | `v6` | Rhythm-first beats and melodic hooks |
| [Synthwave](../library/genres/synthwave.md) | `v6-wild` then `v6` | Neon nostalgia and retro-futuristic texture |
| [Lo-fi Bedroom](../library/genres/lofi-bedroom.md) | `v6-mini` then `v6` | Quiet sketches and intimate mood music |
| [Rock Anthem](../library/genres/rock-anthem.md) | `v6` | Riffs, live energy, and sing-along choruses |
| [Electronic Dance](../library/genres/electronic-dance.md) | `v6` | Club grooves, builds, and drops |
| [Acoustic Folk](../library/genres/acoustic-folk.md) | `v6` | Story-driven acoustic songs |
| [Cinematic Ambient](../library/genres/cinematic-ambient.md) | `v6-wild` then `v6` | Visual moods, spacious cues, and wordless vocals |
| [Bossa and Jazz Pop](../library/genres/bossa-jazz.md) | `v6` | Soft harmony, brushed drums, and relaxed phrasing |
| [Hyperpop](../library/genres/hyperpop.md) | `v6-wild` then `v6` | Bright, maximalist, internet-energy pop |

## Usage note

Choose one playbook per generation. If you want fusion, name the dominant genre and treat the second genre as a single instrument, rhythm, or section-level accent.
