# Edit and Mashup

## Rights gate

Before source-specific guidance, confirm: "I own or have rights to use this source." This applies to voice recordings, audio, images, video, samples, stems, and mashup material. If rights are unclear, give text-only alternatives.

## Local line edit

```text
Make a local lyric edit only.
Section: <section>
Original line: "<exact line>"
Replace with: "<new line>"
Match the existing melody, rhythm, phrasing, voice, key, tempo, and instruments.
Keep all surrounding lyrics unchanged.
```

## Section replacement

```text
Replace one section only.
Target section: <section>
Section job: <tension / lift / reveal / closure>
New section:
[<Section>]
<lines>
Preserve the voice, production, key, tempo, and all other sections.
```

## Voice memo or source audio

```text
I own or have rights to use this source.
Source: <file>, timestamp <mm:ss-mm:ss>.
Target element: <melody / rhythm / lyric / timbre / mood>.
Preserve: <one priority>.
Ignore: <noise or unwanted layer>.
New target: <genre, language, structure, instruments>.
Create original supporting material.
```

## Image or video

```text
I own or have rights to use this visual source.
Visual anchors: <light>, <motion>, <emotional subject>.
Follow: <visual rhythm / mood / narrative arc>.
Target: <duration>, <language or instrumental>, <genre>.
Avoid literal sound effects unless subtle and musical.
```

## Sample, isolate, or mashup

- Sample: preserve one source function, such as riff, bass, rhythm, atmosphere, or call-and-response.
- Isolate: name the target layer and every layer to ignore.
- Mashup: assign one dominant source and one supporting role; avoid simultaneous competing hooks.
- Rebuild: request original drums, bass, transitions, and supporting parts.

## Source failure triage

1. Shorten the timestamp.
2. Choose one preservation priority.
3. Separate what to preserve from what to replace.
4. Remove noise in words before relying on processing.
5. Use `v6` for control; reserve `v6-wild` for a single reinterpretation.
