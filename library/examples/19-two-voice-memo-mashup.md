## Goal
Combine two original voice memos into one coherent lo-fi song with a clear primary identity.

## Model
`v6` for hierarchy, timing, and unified arrangement.

## Inputs
Two user-owned voice memos, source roles, section placement, and a target genre.

## Style Prompt
Original Mandarin lo-fi bedroom mashup, mellow electric piano, soft nylon guitar, quiet bass, lazy brushed drums, tape warmth, close breathy vocal, one main melody and one answering texture.

## Exclude Styles
Do not use commercial recordings, stack both hooks simultaneously, keep room noise, or add a loud EDM drop.

## Lyrics or Edit Instruction
```text
Create an original mashup from my cleared sources. I own or have rights to use all sources.
Source A: memo-hum.m4a, 00:04-00:18, role: main verse melody.
Source B: memo-words.m4a, 00:06-00:12, role: quiet chorus answer.
Hierarchy: Source A is the main identity. Source B appears only in the second half of the chorus.
Resolve both sources into one key and slow tempo. Create original drums, keys, and transitions.
```

## Expected Result
A single lo-fi narrative where one memo leads and the other answers without competing.

## Failure Modes
Two melodies overlap, keys do not resolve, room noise remains, or the result sounds like a collage.

## Next Iteration
Use Source A in verses and Source B only as a wordless answer, then request one new connecting chord progression.

## Evidence
Evidence tier: `official` for multi-source mashup; hierarchy and rights instructions are official-informed.
