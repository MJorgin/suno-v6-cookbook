## Goal
Build an original dance-punk beat around a two-bar guitar riff recorded and owned by the user.

## Model
`v6` for source placement and arrangement control.

## Inputs
Cleared guitar audio, timestamp, recognition level, and target production.

## Style Prompt
Original dance-punk/electronic beat built around the cleared guitar riff, punchy kick, round synth bass, crisp clap, percussive hi-hats, raw but clean mix, one build and one release.

## Exclude Styles
Do not imitate a released song, use uncleared material, keep amp noise, or add a metal guitar wall.

## Lyrics or Edit Instruction
```text
Build an original beat around my cleared source audio. I own or have rights to use this sample.
Source: guitar-idea.wav, timestamp 00:12-00:15.
Element to use: two-bar palm-muted guitar riff.
Recognition level: clearly featured in verses, transformed under filters in the break.
Preserve the riff's rhythm and timbre. Create new drums, bass, and transition sounds.
Target tempo: 124 BPM.
```

## Expected Result
The riff acts as the lead hook, while all surrounding production is newly built and dance-ready.

## Failure Modes
Source noise is preserved, bass clashes with the guitar, or the result evokes a familiar released track.

## Next Iteration
Specify exact bar placement, allow pitch correction by one semitone, and ask for a drumless intro.

## Evidence
Evidence tier: `official-informed`; sampling and rebuild are official v6 capabilities, while this exact beat prompt remains untested.
