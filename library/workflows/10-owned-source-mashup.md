# Owned-Source Mashup

## When to use

Use this to combine two or more cleared sources, such as your own stems, voice memos, riffs, spoken lines, or instrumental loops.

## Recommended model

- Default: `v6`
- Unexpected combination: `v6-wild`, followed by `v6`

## Inputs

- Two or more sources you own or have rights to use
- The role of each source
- Hierarchy: lead, support, transition, texture, or answer
- Genre and tempo target
- Sections where each source should appear

## Recipe

1. Confirm every source is owned or cleared; do not upload commercial releases or ripped audio.
2. Assign each source a single role.
3. Name the dominant source so the arrangement has a center.
4. Define where each source enters and exits.
5. Ask `v6` to create original connecting material and a unified mix.

## Copy-ready template

```text
Create an original mashup from my cleared sources. I own or have rights to use all sources.

Source A:
<file>, timestamp <range>, role: <lead melody / vocal hook / groove>.
Source B:
<file>, timestamp <range>, role: <supporting texture / rhythm / answer>.

Hierarchy:
Make <source> the main identity. Use the other source only in <section or function>.

Target:
<genre>, <tempo>, <language or instrumental>, <structure>, <mix style>.

Create original transitions and supporting parts. Resolve key, tempo, and emotion into one coherent song.
```

## What to preserve

Preserve source roles and hierarchy, not every available detail. A mashup needs a clear lead.

## Failure signals

- Multiple hooks compete at the same time.
- Keys or tempos are stacked without resolution.
- The result sounds like a collage instead of a song.
- A source appears in a section where it was not requested.

## Next iteration

Reduce to one dominant source and one supporting source, assign them to different sections, then regenerate.

## Evidence

Evidence tier: `official` for multimaterial mashup support; `official-informed` for rights, hierarchy, and arrangement guidance.
