# 中文歌词与双语可唱性指南

Suno v6 可以理解更复杂的音乐语言，但中文歌词仍要为“能唱出来”服务。

## 句子长度

- 每句尽量表达一个画面或动作，避免一句塞入两个转折。
- 慢歌每句建议 8–14 个汉字；快歌可更短。
- 主歌可以有轻微长短变化，副歌句子最好更整齐。
- 英文插入词前后留呼吸点，不要连续堆多个英文长词。

## 押韵与语气

- 副歌优先使用开口音、容易延长的尾韵。
- 同一首歌可以主歌叙事、副歌回环，不必每句强行押韵。
- 少用抽象名词连排，例如“孤独、命运、宇宙、自由、时间”连续出现。
- 把情绪落到动作、物件和场景：雨、灯、车门、未发消息、袖口、楼梯间。

## 中英混唱

英文词应当承担明确功能：

- hook 记忆点；
- 标题词；
- 节奏停顿；
- 氛围词。

避免在一句中文里插入发音复杂、重音冲突的英文短语。`light`、`night`、
`run`、`hold on` 这类短音节通常比多音节抽象词更容易唱。

## 数字与专有名词

- 数字优先改成中文或短音节表达，除非数字本身是 hook。
- 产品名、地名、技术术语首次出现后要重复确认发音空间。
- 缩写词谨慎使用，必要时在旁边给出读法或改写。

## 局部改词指令

```text
只把副歌第二句“<原句>”替换为“<新句>”。保持旋律、节奏长度、人称和
尾韵不变，不修改其他歌词，不改变编曲。
```

如果新句字数变化很大，明确允许旋律变化：

```text
允许这一句旋律重新分配，但前后两句和第二遍副歌必须保持一致。
```

## 质检清单

- 断句是否能一口气唱完；
- 人称是否一致；
- 时间线是否清楚；
- 抽象词是否过多；
- 英文词重音是否贴合节拍；
- 副歌是否有一句能被记住；
- 是否保留了中文自然语序，而不是翻译腔。
