## Suggested rollout

| Timing | Action |
|---|---|
| Day 0 | Publish repository, upload social preview, set topics, create the `v0.1.0` release |
| Day 0 | Post the Chinese first-impression note on 即刻/朋友圈 and the English X post |
| Day 1 | Share the HN/Reddit post as a creator seeking workflow feedback |
| Day 2–3 | Respond to issues and convert real failures into new failure notes |
| Week 1 | Add one community-tested example with model, date, prompt shape, and result |
| Week 2 | Publish a short follow-up: “5 Suno v6 prompt failures and how to repair them” |

## Growth angle

The strongest differentiator is not “another prompt list”; it is the combination of model routing, local-edit workflows, Chinese singability, evidence labels, source-rights boundaries, and an agent skill that can be used without a service or credentials.
