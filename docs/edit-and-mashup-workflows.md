# Suno v6 Edit and Mashup Workflows

These recipes are written for v6's text, audio, image, and video workflows. They are practical prompts, not claims that every interface option is available on every plan or in every region.

| Workflow | Best starting model | Use case |
|---|---|---|
| [Text-to-Song](../library/workflows/01-text-to-song.md) | `v6` | Polished song from lyrics, genre, and intent |
| [Vibe-to-Song](../library/workflows/02-vibe-to-song.md) | `v6-wild` | Mood-first exploration |
| [Wild-to-Flagship Refinement](../library/workflows/03-wild-to-flagship-refinement.md) | `v6-wild` then `v6` | Turn surprise into a controlled result |
| [Lyric Micro-Edit](../library/workflows/04-lyric-micro-edit.md) | `v6` | Replace one line without changing the recording |
| [Section Replacement](../library/workflows/05-section-replacement.md) | `v6` | Rewrite one song section |
| [Voice Memo to Song](../library/workflows/06-voice-memo-to-song.md) | `v6` | Turn a cleared recording into a full song |
| [Image or Video to Music](../library/workflows/07-image-or-video-to-music.md) | `v6-wild` then `v6` | Interpret owned visual media |
| [Sample Riff to Beat](../library/workflows/08-sample-riff-to-beat.md) | `v6` | Build around a cleared riff or loop |
| [Isolate and Rebuild](../library/workflows/09-isolate-and-rebuild.md) | `v6` | Extract one layer and replace the rest |
| [Owned-Source Mashup](../library/workflows/10-owned-source-mashup.md) | `v6` | Combine multiple cleared sources |
| [Chinese Singability](../library/workflows/11-chinese-singability.md) | `v6` | Improve Mandarin, Cantonese, or bilingual delivery |
| [Failure Diagnosis](../library/workflows/12-failure-diagnosis.md) | `v6-mini` then `v6` | Debug lyrics, vocals, arrangement, and source edits |

## Rights rule for source-based workflows

Only upload audio, images, video, voice recordings, samples, or stems that you own or have permission to use. The cookbook does not provide instructions for uploading commercial releases, ripped media, unauthorized samples, or voice recordings that impersonate another person.
